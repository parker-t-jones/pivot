# Deep-link candidates

Watch links open with `Linking.openURL` (`app/contexts/SwitchingContext.tsx`). The server builds the https URL (`serviceWatchUrl` and `USER_SERVICE_LANDING_URLS`). The app adds one scheme fallback: ESPN's `sportscenter://watch`, tried with `canOpenURL` and falling back to the https link. `sportscenter` is in `LSApplicationQueriesSchemes`, which a native build has to pick up.

Parker tested these on an iPhone on Oct 2 2026. https links were tapped from Notes. Schemes were typed in Safari. Paramount+ and Peacock opened the app; the screen inside the app is unverified because there was no account.

A non-Thursday Prime game uses `https://app.primevideo.com/search?phrase={Away nickname} vs {Home nickname}`. That query was not in the device pass.

Sources are the page or post that actually states the URL. Community posts are not vendor docs.
